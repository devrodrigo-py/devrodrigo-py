### Sobre mim

Sou Rodrigo, desenvolvedor de sistemas com foco em **gestão, engenharia e produção industrial**.

Meus projetos conectam interfaces, regras de negócio e dados para apoiar o trabalho diário: registrar operações, acompanhar atividades e transformar informações em visões para a gestão. Trabalho com aplicações desktop e interfaces web, usando principalmente Python, React, TypeScript e PostgreSQL.

### Onde concentro meu trabalho

| Área | Aplicações |
| :--- | :--- |
| **Produção industrial** | Apontamentos, acompanhamento de operações e rastreabilidade |
| **Engenharia** | Registro de horas, atividades e acompanhamento de trabalho |
| **Gestão** | Estoque, rotinas administrativas, indicadores e relatórios |
| **Desktop** | Interfaces React integradas a serviços Python no Windows |
